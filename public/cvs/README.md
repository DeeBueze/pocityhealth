# CVs

Drop each team member's CV here as a PDF, named after the person in lowercase with a hyphen:

- bueze-oriaku.pdf
- mayowa-titilola.pdf
- emeka-odiwe.pdf
- zainab-adebayo.pdf

The file names must match the `cv` paths in `/public/js/content.js`.

If a PDF is not here yet, the site tells visitors that the CV is coming soon instead of
downloading a broken file. To show "coming soon" on purpose, set that person's `cv` to `""`.
